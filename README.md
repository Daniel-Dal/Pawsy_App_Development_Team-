# PAWSY APP

El propósito de PAWSY es facilitar el cuidado de las mascotas de manera sencilla y eficaz, proporcionando herramientas que permitan a los usuarios llevar una gestión adecuada de sus necesidades. Entre los aspectos más importantes de la aplicación se encuentran los recordatorios, que permiten programar y recibir avisos sobre actividades esenciales como alimentación, medicamentos, vacunas, citas veterinarias y otros cuidados necesarios. De esta manera, PAWSY busca ayudar a los propietarios a mantener una rutina organizada y garantizar el bienestar de sus mascotas.
