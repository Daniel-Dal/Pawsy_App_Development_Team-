# Funcionalidades

La siguientes es una lista de las funcionalidades disponibles para el usuario de la aplicación:

1. Gestión de perfil de usuario 
2. Creación de perfiles de mascota
3. Acceso a recomendaciones IA
4. Reconocimiento de alimentos por cámara
5. Almacenamiento de historia clinica
6. Acceso a geolocalización de veterinarias y tiendas petshop
7. gestión de cronograma de actividades correspondientes a la mascota
8. comunidad de cuidado de mascotas
9. promoción de eventos de mascota
...
